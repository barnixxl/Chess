# ♟️ Шахматный проект

Добро пожаловать в документацию по функционалу шахматного приложения.  
Здесь описаны все основные возможности: от регистрации до игрового процесса.

---

## 🔐 Регистрация и авторизация

- Пользователь может зарегистрироваться и авторизоваться в системе.  
- Доступна возможность управления аккаунтом:
  - изменение ника;
  - загрузка аватарки;
  - смена почты и пароля.  
- Дополнительные действия:
  - выход из аккаунта;
  - удаление аккаунта.

---

## 👥 Взаимодействие между пользователями

- Добавление друзей по уникальному ID.  
- Возможность играть с друзьями напрямую или с рандомом.  
- Таблица лидеров:
  - рейтинг строится по системе **ELO**;
  - отображаются лучшие игроки.

---

## 🎮 Игровой функционал

- **Игра с компьютером (ИИ)** — тренировка против искусственного интеллекта.  
- **Игра с друзьями или случайными соперниками** — быстрый матч или дуэль с другом.  
- Дополнительные элементы:
  - реплики преподавателей во время игры;
  - красивая анимация:
    - победы;
    - поражения;
    - действий с фигурами.

---

## ⚙️ Прочее

- Настройки игры:
  - включение/выключение звуков;
  - выбор цветовых схем;
  - другие параметры персонализации.
